## Что уже есть

Первый учебный пример: один актор Ray хранит счётчик и выполняет 100 команд
«прибавить 1». Программа проверяет начальное значение, результат каждой операции,
итоговое значение и выполнение актора в отдельном процессе.

Состояние счётчика хранится в памяти процесса актора. Пример проверяет
запуск Ray и работу актора без сбоев.

## Первый запуск

Нужен Python 3.12. Все команды выполняются в корне этого репозитория.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python examples/counter.py
```

Ожидаемый вывод, помимо служебных сообщений Ray:

```text
Отправлено операций: 100
Ожидаемое значение: 100
Полученное значение: 100
Проверка пройдена: актор выполнил все операции в отдельном процессе.
Результат сохранён: runs/counter.json
```

Можно изменить число операций и место сохранения результата:

```bash
python examples/counter.py --increments 250 --output runs/counter-250.json
```

Каталог `runs/` исключён из Git. Проверенные свидетельства этапов сохраняем
отдельно в `nis/evidence/`.

## Как читать пример

- `@ray.remote` превращает класс `Counter` в актор.
- `Counter.remote()` создаёт актор в отдельном процессе.
- `counter.increment.remote()` отправляет ему команду.
- `ray.get(...)` ожидает результаты.
- Все вызовы поступают от одного клиента одному обычному синхронному актору.
- `max_restarts=0` и `max_task_retries=0` явно отключают перезапуски и повторы
  для этого примера.
- `ray.shutdown()` отключает клиент и завершает созданный им локальный Ray.

## Версия Ray

Для первого учебного запуска используем опубликованный пакет **Ray 2.59.0**.
Точные версии зависимостей зафиксированы в `requirements.txt`.

В задании основная ревизия Ray — `2ff4d94078ee94b3c9e6e4552ad84f78bad7f75f`.
Готовая официальная сборка этой ревизии для macOS arm64 / Python 3.12
по стандартному адресу на 22.10.2026 вернула HTTP 404.
Сохранённые результаты примера получены на релизе 2.59.0.
Подробности: [среда и ограничения](nis/environment.md).
